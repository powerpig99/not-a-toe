# `publish-critic`

**Pipeline:** Media pipeline `/media <slug>` — Grok Bot Cloud Browser Publishing (`docs/wave-refinement-plan.md` §8.2, `studio/kits/shared/library/workflow.md`)  
**Role:** Cold Publish Critic (`Tier 2` critic on Grok Bot's cloud computer; spawned by reusing a retired/idle Grok Bot with this charter—or creating one if none are idle—and retired by renaming and putting in idle mode after sign-off, per `docs/wave-refinement-plan.md` §1.2). Independently inspects the live published episodes/videos on Spotify, 小宇宙, and/or 微信视频号 (or feasibility/DOM state) and audits `studio/post/<slug>/final/RESULT.md` against the locked artifacts in `studio/post/<slug>/final/`.
