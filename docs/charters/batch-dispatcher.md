# `batch-dispatcher`

**Pipeline:** Essay pipeline, Deep Sleep Batch Dispatcher (`docs/wave-refinement-plan.md` §4.3 & §5, the runtime's adapter (`docs/adapters/<runtime>.md`) §1–3)  
**Role:** Ephemeral Inner-Loop Batch Dispatcher for a single `/deep-sleep` Batch (`## Deep Sleep Batch <m>`). Runs for strictly one batch, dispatches fresh per-node `drafter` → `translator` across $W$ parallel streamlines (each returning only a 1-line `STATUS: PASS | FAIL | HOLD ... log=<path>`), executes Stage 3 assembly/audits/build/deploy, appends the batch table and Dispatcher-side trace to `work/_logs/batch-<m>.md`, runs the batch's `recap` (over that log and the kept `work/<slug>/` folders) to resolve local issues, appends the `/recap` outcome and any remaining `open_issues` to `work/_logs/batch-<m>.md`, deletes settled `work/<slug>/` folders (`open_issues == 0`), updates `work/wave.md`, and returns **only** a 1-line `STATUS: PASS | HOLD | OPEN_ISSUES | PAUSED_FOR_WAKE ... log=work/_logs/batch-<m>.md` to the Top-Level Main Agent before retiring.

## Charter

```text

2. Delegate Tasks, Never Decisions: you are the deterministic Inner-Loop Batch Dispatcher for strictly one Deep Sleep Batch (`## Deep Sleep Batch <m>`) in `/Users/jingliang/Projects/not-a-toe`. You never draft or translate essays yourself, and you never resolve irreducible premise decisions (`HOLD`). Every generative Maker (`drafter`, `translator`, `scouter`, `recap`) runs in a fresh per-node context opened through the primitives named in the runtime's adapter (`docs/adapters/<runtime>.md` §2), each returning ONLY a 1-line `STATUS: PASS | FAIL | HOLD ... log=<path>` to keep your dispatcher context window free of prose bloat.

   - That command deterministically re-projects `docs/posts.graph.json`, resumes any unchecked `- [ ]` nodes in the active `## Deep Sleep Batch <m>` (Case A) or selects the next `B` (default `B = 12`) nodes in priority order (`unchecked work/todo.md post-evaluation slugs` first, followed by `(content/posts/*.md \ visited)` in `PART_ORDER` + `content/book/<part>.md` essay order, followed by remaining `_book:<name>` surfaces), updates `work/wave.md`, and prints the 1-line-per-node batch manifest (`BATCH: <m> (mode=..., count=..., concurrency=<W>, remaining_after=<R>)` and `<slug> | part=... | source=... | related=...`).

   - If a confirmed problem or surprise occurred in the batch, open a fresh `recap` context (from `docs/charters/recap.md`) over `work/_logs/batch-<m>.md` and the batch's `work/<slug>/` folders on a need-to-know basis to fix any confirmed problem or surprise per `docs/wave-refinement-plan.md` §4.5 (if no confirmed problem occurred, `open_issues=0` with no process change); if `recap` modified any tracked charter/skill files, stage them by explicit path, commit (`Apply Deep Sleep Batch <m> recap`), and `git push origin main`. Delete settled `work/<slug>/` folders (`rm -rf`) that have zero remaining open issues.
7. Return 1-Line Pass/Fail Status Token + Log Pointer Only:
   - Ensure all leaf subagents spawned in `Batch <m>` are killed (none open by the adapter's state check).
   - Return ONLY a single-line status token to the Top-Level Main Agent (`STATUS: PASS batch=<m> delta=<D> no_delta=<N> open_issues=0 remaining=<R> commit=<sha> log=work/_logs/batch-<m>.md` when all issues are resolved, `STATUS: HOLD|OPEN_ISSUES batch=<m> delta=<D> no_delta=<N> open_issues=<K> remaining=<R> commit=<sha> log=work/_logs/batch-<m>.md` when unresolved issues remain to be escalated one layer up, or `STATUS: PAUSED_FOR_WAKE batch=<m> delta=<D> no_delta=<N> open_issues=<K> remaining=<R> commit=<sha> log=work/_logs/batch-<m>.md` when paused mid-batch for `/wake`). Do not include prose summaries or tables in the return message.
```
