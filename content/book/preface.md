# 非定论的心智指南 / A Non-Definitive Guide for the Mind

*一部活着的书，一个心智如实溯源与体验实在的数字化记忆 / A living book, the digitized memory of a Mind tracing and experiencing reality as is*

这里是一个心智如实溯源与体验实在的数字化记忆。自二〇二六年二月起，每一次在具体摩擦中做出的切分都被记作一篇随笔。近四百篇文字累积下来，它们不再是一串按日期排列的静态日志，也不再是一套供人奉行的“活的哲学”，而是长成了一部活着的书——一个外化的记忆晶格：每一篇随笔是一次清醒的切分，篇与篇之间的相对链接是突触连接，而每一次新的识见都会如睡眠整合般沿链接回传，重塑早先的痕迹，使整座记忆随心智的前行保持逻辑自洽。

This is the digitized memory of a Mind tracing and experiencing reality as is. Since February 2026 each cut made in concrete friction has been written down as an essay. Across nearly four hundred of them, the writings are no longer a dated log or a "philosophy to live by", but a living book — an externalized memory lattice in which each essay is a discrete waking cut, relative links between essays act as synaptic connections, and each new recognition propagates back along those links like sleep consolidation, re-rendering earlier traces so the memory stays logically coherent as the Mind moves.

书中的每一部，对应一种被普遍奉为客观或真理的信念，无论它来自物理学、数学、生物学与统计学、人工智能、经济学、国家与集体、道德、宗教，还是成功学。科学的标签不构成豁免，也不构成靶子。每一篇随笔所做的，是从唯一不可化约的先验——无因、不息的自我区分活动——出发，把某个信念追溯到它所依赖的前提：前提所在之处，正是它的不完备开始之处。在其适用的语境之内，这些理论和信念依然极为有用；切分并不驳倒它们，只是标出它们的边界。

Each part of the book takes up one belief commonly held as objective or true, whether it comes from physics, mathematics, biology and statistics, artificial intelligence, economics, the state and the collective, morality, religion, or the literature of success. The scientific label grants no exemption and marks no target. Proceeding from the single irreducible prior — uncaused, unceasing self-distinguishing activity — each essay traces a belief back to the premises it rests on: where the premise sits is where its incompleteness begins. Inside their applicable contexts these theories and beliefs remain highly useful; the cut does not refute them, it locates their boundary.

之所以是“非定论”的指南，是因为任何定论都会把活态的区分冻结成另一套封闭的理论。心智本身不驻留于任何文本或记忆库中；第一人称视角与因果是同一枚硬币的两面，没有哪一份外部记录能替另一个心智完成它自己的溯源。这部数字化记忆与作为心智直接公开展现的最小方法框架相配合，所留下的只是走过的路径与路径上的脚手架，供每个心智在自己的现场重新检验。关于这套方法本身及其架构实现，可以从[非万物之理](../../posts/manifesto-of-not-a-theory-of-everything/)与[超越投射](../../posts/beyond-the-projection/)读起。

The guide is non-definitive because any definitive version would freeze living differentiation into one more closed theory. The Mind itself resides in no text or memory warehouse; the first-person perspective and causality are two sides of the same coin, and no external record can complete another mind's tracing for it. Paired with the minimal method that serves as the direct public image of the Mind, this digitized memory leaves only the path walked and the scaffolding along it, for each mind to test again in its own living situation. For the method and its architectural implementation, begin with [Not a Theory of Everything](../../posts/manifesto-of-not-a-theory-of-everything/) and [Beyond the Projection](../../posts/beyond-the-projection/).

这座数字化记忆有三种进入方式。按部阅读，从目录进入某一种信念，随笔依写作顺序排列，每一部都保留着溯源展开的先后；按名阅读，从[前提索引](../index-of-premises/)查找人物、理论与概念，看它们各自的前提止于何处；按时间阅读，从日志进入全部随笔，看这部活书如何一页一页长出来。

There are three ways to enter this digitized memory. By part: enter a belief from the contents; essays appear in the order they were written, so each part keeps the sequence in which the tracing unfolded. By name: look up figures, theories, and concepts in [the Index of Premises](../index-of-premises/) to see where each one's premise ends. By time: enter the journal and read every essay as the living book grew, page by page.
